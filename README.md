# GameShop

Fullstack web application for a game store built with React, Node.js, Express, and MongoDB.

## Description

GameShop is a fullstack application that simulates an online game store where users can browse products and perform CRUD operations.

The project was built as a practical application to demonstrate frontend and backend development skills.

---

## Features

- Browse game products
- CRUD operations (create, read, update, delete)
- REST API integration
- Responsive UI
- Client-side routing
- Forms handling (Formik)
- State management (Redux Toolkit)

---

## Tech Stack

### Frontend:
- React.js
- Redux Toolkit
- React Router
- Formik
- HTML5 / CSS3 / SCSS

### Backend:
- Node.js
- Express.js
- MongoDB (Mongoose)
